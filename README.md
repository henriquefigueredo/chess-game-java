# Sobre o projeto
Este projeto consiste no desenvolvimento de um sistema de jogo de xadrez funcional desenvolvido inteiramente em Java. O objetivo principal foi aplicar conceitos avançados de Programação Orientada a Objetos (POO) para criar uma lógica robusta e organizada.

Principais Funcionalidades
Lógica de Movimentação: O sistema valida a posição de cada peça individualmente, respeitando as regras oficiais do xadrez.

Interface via Terminal: O jogo é executado diretamente no console, proporcionando uma experiência leve e focada na lógica do backend.

Regras Especiais: Implementação de movimentos e estados do jogo, garantindo que a partida flua corretamente de acordo com as jogadas realizadas.

Desafios Técnicos
O desenvolvimento focou em tratar a complexidade das interações entre as peças no tabuleiro, utilizando estruturas de dados eficientes para o controle de posições e turnos.

### Como executar o projeto

**Via Prompt (CMD):**
1. Vá até o diretório (neste caso substituir pelo caminho onde estará alocado seus arquivos):
   ```bash
   cd C:\temp\ws-eclipse\chess_system\bin
   ```
2. Execute o programa:
  ```bash
   java application/Program
  ```
3. Outra opção é executar diretamente no Git Bash, na pasta \bin execute:
  ```
  java application/Program
  ```
